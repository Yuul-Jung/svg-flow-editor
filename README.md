# SVG Flow Editor v4.0

기존 [html-editor/svg-flow-editor](https://github.com/Yuul-Jung/html-editor/tree/main/svg-flow-editor)의 작동 소스를 별도 저장소로 복제한 개선 버전입니다. 기존 저장소는 수정하지 않습니다.

## 사용

- 브라우저에서 `index.html` 열기
- 구조화 도면의 도형 선택 후 방향키 이동 (Shift+방향키: 1px)
- 연결선 선택 후 꺾임점 핸들 드래그
- 연결선 속성에서 **수동 꺾임 초기화 · 자동 경로 복귀**
- 도형 선택 후 **Ctrl+D** 복제 (선택 집합 내부의 연결선도 복제)
- 실행 취소/다시 실행 시 존재하는 선택 개체 유지

## 검증 상태

- GitHub 파일 업로드와 정적 코드 확인 완료
- 실제 브라우저 상호작용, JSON 왕복, 다중 페이지 및 기존 기능 회귀 테스트는 **미검증**
- 꺾임점별 독립 좌표 저장, 자동 저장/복구, 충돌 탐지, 페이지별 이력은 후속 구현 대상

## 개발 원칙

- 기존 성공 버전 보존
- 실물 브라우저 검증과 정적 검증을 구분
- SoC 교육용 도면의 실제 입출력·누적 동작과 도면 정합성 별도 검증

## v4.1 변경 이력

- 화면 렌더링 중 도형 위치를 자동 변경하던 동작 제거
- 제목 구분선이 도형 영역에 진입하면 구분선 표시를 생략
- 페이지별 Undo/Redo 기록 분리 및 새 도면 교체 시 이력 초기화
- 꺾임점 핸들 인덱스와 저장된 좌표 배열 인덱스 일치

**검증 구분:** GitHub 소스 반영 및 정적 코드 확인. 실제 브라우저 조작과 JSON 저장·재불러오기 왕복 테스트는 아직 미완료.


## 제2부 01~10장 다중 페이지 자료 (2026-11-08)

- 편집기: [GitHub Pages](https://yuul-jung.github.io/svg-flow-editor/)
- 파일: `chapters/P2_01_pages.json` ~ `chapters/P2_10_pages.json`
- **10개 장 × 2페이지 = 20페이지**: 1페이지 주요 UART/CPU 제어 흐름, 2페이지 장별 기능 상세·독립 RTL/AXI 동작 구분
- `chapters/P2_02.json` ~ `P2_10.json`: 이전 단일 페이지 데이터도 보존하여 호환 가능
- 01장은 기존 내장 `baseScene()`도 보존하되, 상단의 **01장 열기**로 신규 2페이지 자료 선택 가능
- 오른쪽/하단의 파란 **페이지 연결 노드**는 수업자료 페이지 이동만 나타내며, C/RTL 알고리즘의 제어 흐름이 아님
- 화면의 1/2 페이지 선택·다음/이전, 페이지 추가·이름 변경·JSON 작업 저장·불러오기 사용

### 확인 범위

- 정적 확인: 10개 파일 JSON 구조, 20페이지 노드·간선 참조, 페이지 이동 대상, 캔버스 경계·노드 중복 검사
- 설계 및 C/RTL 대응은 일부 검토되었으나 모든 장의 RTL 시뮬레이션, Vivado 합성·타이밍, Basys3 실물 검증과 별개
- 각 페이지의 `DESIGN_DRAFT_NOT_CODE_VERIFIED` 표시는 실제 검증 통과를 뜻하지 않음
- 모바일 브라우저 조작과 Pages 배포 표시의 실시간 재현은 별도로 확인 필요

**원본:** 02~10장 단일 JSON 및 제2부 02장 2페이지 자료는 `Yuul-Jung/html-editor` 저장소에서 보존·이관한 자료이며, 새 저장소에서 적용한 기능 상세 도면은 교육용 설계 개념입니다.
